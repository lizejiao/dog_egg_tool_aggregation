# 格式问题：折行 / 缩进 / 字体 / 分页

这份笔记记录 md→PDF 在格式上反复踩过的坑和验证过的处理方式。调脚本或自检时先读。

## 1. 折行（最常见问题）

**现象**：一行没写完就自动换行，而且断在难看的位置——把 `Function Calling`、`VS Code Copilot`、`RAG / 排障`、`Token 消耗` 这类英文/混排术语拦腰拆到两行。

**根因**：reportlab Paragraph 默认在任意空格处断行。中英混排的句子里空格很多，它就挑空格断，断着断着把术语拆了。

**处理（已固化在 render.py 的 `inline()`）**：
- 把**所有普通空格（U+0020）替换成不间断空格（U+00A0，即字面字符 `"\xa0"`）**，让 reportlab 不在空格处断行。
- 所有 Paragraph 样式设 `wordWrap="CJK"`，允许它在中文字符 / 中文标点（，；、。）处断行。
- 效果：英文术语连成整体不断开；断点顺移到中文标点处，整句仍能正常换行，只是不再拆词。

**注意**：
- 不要用 `&nbsp;` 字符串。`inline()` 第一步就把 `&` 转义成 `&amp;`，写 `&nbsp;` 会变成字面文本打印出来。必须用**字面 `"\xa0"` 字符**。
- 替换空格前，必须先用正则把 `<...>` 标签切出来，只替换标签外的空格。否则 `<font color="#888">` 里 `font` 和 `color` 之间的空格也被替换，HTML 解析会报 `saw </font> instead of expected </para>`。

## 2. 缩进 / 列表层级

**现象**：二级列表被当成普通段落，行首 `-` 被字面打印出来；或者缩进层级判断错乱。

**处理**：
- 先 `stt = s.strip()` 判断是不是 `- `/`* ` 开头。
- 再用 `indent = len(raw_line) - len(raw_line.lstrip(" "))` 算行首缩进。
- `indent == 0` → 一级 `• `；`indent >= 2` → 二级 `◦ `（leftIndent=16）；`indent >= 4` → 三级（leftIndent=30）。

## 3. 字体

- macOS 用 `/System/Library/Fonts/STHeiti Light.ttc`（正文）和 `STHeiti Medium.ttc`（粗体），注册成 `Heiti` / `Heiti-B`。
- 必须 `registerFontFamily("Heiti", normal=..., bold=...)`，md 里的 `**粗体**` 才能真的渲染成粗体，否则 `<b>` 会被忽略。
- 不要用 Unicode 上下标字符（₀₁₂₃…），内置字体没这些字形，会渲染成黑块。

## 4. 分页 / 字号跷跷板

- 字号 ↔ 页数是反向关系：`--font-size` 调大，版面舒展但容易多撑一页；调小，折行少但页底空。
- 内容溢出到下一页（哪怕只有一两行）：把字号调小 0.2，或把 `--margin` 从 12 收到 11。
- 某页空大半：把字号调大 0.2~0.3，或加大 `##` 标题的 spaceBefore。
- **不要为了消灭折行而无限缩字号**——缩到 8pt 以下整页显小、不专业。折行优先用第 1 节的"不间断空格"解决，缩字号是最后手段。

## 5. 不丢内容（最容易被忽略）

- **不要硬编码行号截断**（如 `lines[25:]`）。md 头部行数一变就会把后面的分节整段丢掉。脚本按 `#/##/###/####` 标题逐行顺序渲染，从第一行开始扫，不跳行。
- **未知行按普通段落兜底**，不要 `continue` 掉。任何 md 里写了的内容，在 PDF 里都应该出现。
- 生成后用 PyMuPDF 抽全文文本，对照 md 确认没有缺段：

```python
import pymupdf
d = pymupdf.open(out_pdf)
text = "".join(p.get_text() for p in d)
# 抽查 md 里几个关键短语是否都在 text 里
```
