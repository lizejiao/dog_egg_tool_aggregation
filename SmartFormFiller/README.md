# SmartFormFiller - 智能表单自动填充 Chrome 插件

基于模糊匹配算法的智能表单自动填充工具。自动检测页面表单元素，根据用户预设信息智能匹配并自动填写。

## 功能特性

- **智能检测** - 自动扫描页面所有表单元素，从 label、placeholder、name、id、aria-label、邻近文本等 6 个维度提取上下文信息
- **模糊匹配** - 基于 LCS（最长公共子序列）+ Jaccard 字符集重叠 + 包含关系的三重评分算法
- **一键填充** - 点击按钮即可自动填充当前页面所有匹配的表单
- **多配置管理** - 支持创建多个配置档案（Profile），方便不同场景切换使用
- **灵敏度可调** - 匹配阈值 0.1~0.9 可调，灵活控制匹配严格程度
- **填充高亮** - 成功填充的字段短暂绿色高亮提示
- **框架兼容** - 使用 native setter + 事件派发，兼容 React/Vue 等框架

## 安装方法

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目文件夹 `SmartFormFiller`

## 使用方法

### 1. 配置基本信息

- 点击浏览器工具栏的插件图标
- 切换到「信息管理」标签
- 点击「+ 新建」创建配置档案
- 添加匹配关键字和对应的填充值：

| 匹配关键字（示例） | 填充值（示例） |
|---|---|
| 小红书名字 | 张三 |
| 小红书粉丝量 | 666 |
| 小红书简介 | 热爱生活的小仙女 |
| 微信昵称 | 张三丰 |
| 手机号 | 13800138000 |

### 2. 自动填充

- 打开目标页面（如小红书创作者中心）
- 点击插件图标 → 点击「一键填充当前页面」
- 插件自动匹配并填充表单字段

### 3. 调试扫描

- 点击「扫描页面字段」查看当前页面检测到的所有表单元素及其上下文信息
- 用于检查匹配关键字是否合理、调试匹配效果

## 匹配算法说明

采用三重评分机制：

| 维度 | 权重 | 说明 |
|---|---|---|
| LCS 相似度 | 45% | 最长公共子序列长度占两字符串总长度的比例 |
| Jaccard 重叠度 | 35% | 字符集合的 Jaccard 相似度 |
| 包含奖励 | 20% | 如果一方完全包含另一方，给予额外加分 |

所有文本在匹配前会进行归一化处理（去除空格、标点、转小写）。

### 匹配效果示例

| 页面表单文本 | 预设关键字 | 匹配结果 |
|---|---|---|
| "请输入小红书名字" | "小红书名字" | 包含匹配 |
| "小红书粉丝数量" | "小红书粉丝量" | LCS 模糊匹配 |
| "小红书简介" | "小红书简介" | 精确匹配 |
| "xhs昵称" | "小红书名字" | 不匹配 |

## 设置说明

| 设置项 | 说明 | 默认值 |
|---|---|---|
| 匹配灵敏度 | 值越低越宽松（可能误填），值越高越严格（可能漏填） | 0.4 |
| 高亮已填充字段 | 填充后字段短暂绿色高亮 | 开启 |
| 显示填充数量角标 | 插件图标上显示填充数量 | 关闭 |
