#### ④ 房交易业务 —— 主导房金融账本核算业务

- **业务背景：**&#x73B0;金赎楼业务流程，主链路为：**授信 → 用信 → 合同借据（签约 → 放款 → 还款）→ 清偿 → 过户 → 核抵**。
  - **授信：** 提交申请材料，确定客户等级、利率等关键信息。
  - **用信：** 提交行为证明，完成房屋抵押核实、回款来源核实；通过后基于某笔抵押信息创建合同借据。
  - **合同借据流（3 节点）：**
    - **签约：** 客户登录安居客-交易宝签订合同；人脸核验不通过时，可就该笔订单开启短信签约。
    - **放款：** 提交 24h 产调，风控审核通过后系统自动调用资金平台放款。
    - **还款：** 买方按揭贷款到位后，由卖方来还款结清。
  - **清偿：** 提交结清抵押款证明并审核。
  - **过户：** 提交解抵押、过户证明并审核。
  - **核抵：** 提交上抵证明并审核。
- **核心功能：**
  - **借据与放款：** 资金平台放款成功后自动生成电子借据，记录本金、利率、期数、还款方式与关联抵押信息，作为后续账本核算的源头凭证。
  - **还款计划：** 按等额本息 / 先息后本等方式预生成全周期还款计划（应还本金、应还利息、还款日），支持提前还款、部分还款后计划重算与展期处理。
  - **利息与罚息计算：** 按日计息，支持固定利率与阶梯利率策略；逾期自动触发罚息，按逾期天数与剩余本金阶梯计息，兼顾合规口径与业务灵活配置。
  - **账本功能：** 维护客户 / 借据维度的虚拟账户账本，实时记录放款、还款、利息、罚息、费用等流水，支持余额实时查询与历史穿透追溯。
  - **收益计算：** 按借据与渠道维度核算利息收入、服务费、渠道分润等，输出业务收益报表，支撑经营决策。
  - **还款处理：** 支持主动还款、代扣还款、提前结清；资金到账后按「罚息 → 费用 → 利息 → 本金」优先级自动冲账，同步更新账本与还款计划状态。
  - **对账与日终跑批：** 与资金平台、渠道方、财务系统自动对账，日终批量核对流水与余额，差异自动告警并挂账处理，保证账实一致。
