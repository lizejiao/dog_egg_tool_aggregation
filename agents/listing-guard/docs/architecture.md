### 五个子图各自回传的因子（上下文隔离契约）

| 子图 | 回传因子 | 不外泄的中间数据 |
|---|---|---|
| ① form_audit | form_rules | 规则命中明细 |
| ② image_vlm | image_authenticity、image_text_consistency | 逐图判定、base64、OCR 全文 |
| ③ video | video_authenticity | 逐帧判定、ASR 转写全文 |
| ④ text_risk | text_risk | 逐条命中明细、语义层原始输出 |
| ⑤ base_info | community_match、price_reasonable、listing_duplicate、credit | 三库查询原始行 |

子图间受控数据流：图片材料的 pHash 由主图入口传给基本面子图做房源级查重强证据
（跨发房人 pHash 命中 = 盗图重复贴）。

## State 设计（`state.py`）

- **并行写入安全**：`factors`（dict 合并）、`events`/`injection_hits`（list 追加）都挂 reducer，
  5 子图 + 政府核验同超步并发写不冲突；这也是 LangGraph 扇出的硬性要求。
- **只存结构化结论**：图片明细（base64/OCR 全文）、ASR 转写全文、子图内部命中明细
  都只存在于各子图内部，回传主图前收敛为因子——子图上下文隔离，state dump 可读、不爆。
- **可回溯**：`policy_version`（因子表+阈值内容哈希）随 state 落检查点，
  任何一次历史判定都能对上当时用的策略版本。

## 断点续跑机制（`gov_verify.py` + `builder.py` + SqliteSaver）

1. 节点首次进入：`ensure_request`（幂等）登记核验请求 → `interrupt()` 抛出挂起；
   此刻已完成算子的结果已写入 SQLite 检查点（`checkpoints` / `writes` 两张表，
   每超步一快照，`thread_id` = 审核单号）；
2. 进程退出；回调到达后（`scripts/callback_sim.py` 或 `resume_case.py --resume`），
   新进程以同 thread_id + `Command(resume=回调数据)` 恢复；
3. 被中断节点**重新进入**（LangGraph 语义），`interrupt()` 这次直接返回回调值——
   因此"发起请求"必须幂等（见 `gov_api.mock_callback` 的投递标记设计）；
   其他已完成节点从检查点恢复 state，**不重跑**（`tests/test_resume.py` 逐节点断言只执行一次）。

同一机制复用三处：政府核验回调、人工复审裁决、房东补拍材料。

## 决策语义（`routes.py` + `aggregate.py` + `decide.py`）

- **非对称阈值**：放行 0.85 / 拦截 0.35（`config/thresholds.yaml`，可按城市覆盖），
  中间地带一律转人工——误杀优质房源的房东流失不可逆；
- **否决项不进平均**：盗图/合规红线/政府核验失败等 veto 因子由路由层短路
  （reject 驳回 / human 转人工），正分不能把黑名单"平均"回及格线；
- **降级重归一化**：算子超时/异常标记 `degraded` 并从加权分母剔除，
  而非记 0 分——单算子故障不阻断、不误杀；
- **注入防护**：用户文本只作为待检测数据，命中特征强制转人工；
  live 模式下模型只输出 JSON Schema 约束的结构化判定，自由文本不影响路由。

## 评测口径（`scripts/batch_eval.py`）

- 归桶看**路由去向**而非人工裁后终态：`human_approved/human_rejected` 都算"转人工"，
  人工裁决只是复核结论，不影响"低置信样本被精准转人工"这一路由事实；
- 误杀红线 = expected pass 判 auto_reject（batch 始终为 0）；
- fixtures 刻意偏边界样本（9 条里 6 条异常），自动覆盖率 56% 是样本分布使然，
  不是模型能力上限——真实流量下优质房源占大头。
