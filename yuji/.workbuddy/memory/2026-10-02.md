## 修复：馆主管理后台白屏
- 现象：进入「管理后台」页面白屏，无任何渲染
- 根因：`utils/admin.js` 导出 `module.exports = { guard }`，但全部 8 个管理页写的是 `const guard = require('.../utils/admin')` 后直接 `guard()` 调用 → onLoad 抛 `TypeError: guard is not a function`，`ready` 永远 false，WXML 根节点 `wx:if="{{ready}}"` 不渲染
- 修复：改 `utils/admin.js` 为 `module.exports = guard; module.exports.guard = guard`，同时兼容「直接调用」与「解构调用」两种引入方式，一处改动覆盖全部管理页
- 验证：node 模拟两种 require 方式均返回 function 且调用正常
