# 2026-10-01 工作日志

## 瑜伽馆小程序（yuji）完整搭建

用户需求：微信原生云开发，瑜伽馆课程预约 + 会员课时管理，学员/馆主双角色。

### 交付内容
- 14 个页面：首页(课程列表+公告)、课程详情(预约/取消)、我的、我的预约、我的套餐、签到记录；管理后台：home、课程管理/编辑、会员管理/详情、预约管理(签到/取消)、课时统计、公告管理。
- 7 个云函数：login / course / booking / member / package / notice / init（cloudfunctions/）。
- 数据库集合：users、course、order、package、signin + 辅助 hourslog(课时流水)、notice(公告)。
- 时间字段统一存毫秒时间戳(Number)，另存 startTimeStr/dateKey 便于展示与按天统计，规避 Date 序列化时区问题。
- 预约/签到/课时调整均用云数据库事务（db.startTransaction），签到扣 1 课时并优先消耗先到期套餐。

### 关键决策
- 渲染器从脚手架默认的 Skyline 改回 WebView（去除 navigationStyle:custom），兼容性更好、代码更易维护。
- tabBar 图标用纯 Python（zlib+struct）生成的 PNG，脚本在 scripts/gen_tab_icons.py，莫兰迪灰绿 #8FA68E / 灰 #B4BAB5。
- 管理员权限：users.role === 'admin'；两种升级方式——cloudfunctions/login/index.js 里的 ADMIN_OPENIDS 数组，或「我的 → 馆主入口」输入口令（默认口令 yoga2026，写在 login/index.js 的 ADMIN_PASSWORD）。
- 首次部署：调用 init 云函数建集合+写入演示数据；「我的」页有初始化入口。
- 手机号优先 getPhoneNumber(cloudID 解密)，个人主体小程序自动降级为手动输入。
